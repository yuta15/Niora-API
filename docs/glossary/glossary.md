# 用語集

| 用語 | 英語名 | 説明 |
| --- | --- | --- |
| 教科書 | `Textbook` | 学習者へ提供する教材。複数の章で構成する |
| 章 | `Chapter` | 教科書を構成する学習単位。学習内容と対応するWorkspaceDefinitionを持つ |
| ワークスペース定義 | `WorkspaceDefinition` | Workspaceを作成するために必要な設定 |
| ワークスペース | `Workspace` | WorkspaceDefinitionをもとに起動された、操作可能な学習環境 |
| 接続トークン | `ConnectionToken` | 特定のWorkspaceへの接続だけを許可する、有効期限の短い認証情報 |
