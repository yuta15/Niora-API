# アーキテクチャ決定記録（ADR）

Niora APIのアーキテクチャ上の重要な意思決定を記録します。

決定済みのADRは[決定記録一覧](decisions.md)で管理します。

## ファイル名

連番と短いタイトルを使用します。

```text
0001-define-version-0.0.1-scope.md
0002-prioritize-architecture-characteristics.md
```

## テンプレート

```markdown
# 0001: タイトル

## 背景

判断が必要になった背景や制約を記載します。

## 決定

採用する方針を記載します。

## 代替案

検討したほかの選択肢を記載します。

## 影響

決定によって生じる利点、欠点、制約を記載します。
```
